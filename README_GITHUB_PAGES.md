# Go Life Lab — GitHub Pages 무료 공개용 패키지

Go Game Guru SGF 422개 + 기존 기본 배치 35개 + 420개 한국어 학습 해설 + 오답 복습/리포트 기능을 내장한 비상업적 바둑 사활 웹앱입니다.

## 업로드 순서

1. ZIP 압축을 풉니다.
2. GitHub의 **새 저장소**를 만들거나 기존 Go Life Lab 저장소의 파일을 교체합니다.
3. 이 폴더의 **전체 파일**을 저장소 최상단에 업로드합니다. 특히 `index.html`, `manifest.webmanifest`, `sw.js`, 아이콘, `CREDITS_AND_LICENSE.html`, `LICENSE_GoGameGuru.txt`, `SOURCES_422.csv`를 함께 올려야 합니다.
4. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)` → Save.
5. 배포 후 [앱 주소]에서 **저작권·출처 보기**를 열어 원문·출처 링크가 작동하는지 확인합니다.
6. 모바일에서 홈 화면에 추가 또는 앱 설치 후 문제 풀이와 백업을 확인하세요. 첫 접속·업데이트에는 인터넷이 필요합니다.

## 콘텐츠 이용 조건

**Go Game Guru의 CC BY-NC-SA 4.0 조건이 적용되는 것은 원본 문제·번역·변형 콘텐츠입니다.** 공개 사이트는 무료·비상업적으로만 운영하고 광고·유료 서비스·제휴 추천 수익을 넣지 마세요. 앱은 Go Game Guru 공식 서비스가 아님을 분명히 합니다.

콘텐츠 원본 및 라이선스: `CREDITS_AND_LICENSE.md`, `CREDITS_AND_LICENSE.html`, `LICENSE_GoGameGuru.txt`, `SOURCES_422.csv`.

## 사용자 데이터 및 업데이트

학습 기록은 사용하는 브라우저의 로컬 저장소에 보관합니다. 외부 서버로 자동 업로드하지 않습니다. 주소·브라우저·앱 설치 경로를 바꾸면 기존 기록이 자동 이전되지 않을 수 있으니 **기록 → 전체 학습 데이터 백업**을 먼저 사용하세요.

PWA 서비스 워커는 첫 실행 이후 오프라인 읽기를 위한 캐시를 사용하지만, 최초 설치 및 실제 기기별 동작은 업로드 후 반드시 확인하세요. 일반 개인 계정에서 GitHub Pages 주소는 공개됩니다.
