# Go Life Lab — 14단계: 문제당 오답 기회 3회

- 정답 수순에 없는 합법적인 착수 또는 원본에 명시된 실패 변화도는 **틀린 시도 1회**로 계산합니다.
- 아이가 정상적인 정답 수순을 진행하는 수, 또는 규칙상 불가능한 위치를 누른 것은 차감되지 않습니다.
- 틀리면 **바둑판을 문제 시작 상태로 되돌리고**, 남은 기회 2회 / 1회가 표시됩니다.
- 세 번째 오답 후에는 `failure` 기록을 **한 번만** 저장해 오답 복습/7일 리포트에 반영합니다.
- 일반 사활 문제는 2.3초간 실패 안내를 보여준 뒤 다음 문제로 넘어갑니다. 기초 점검은 다음 점검 문제로 진행합니다.
- 오답 복습 중에는 다음 복습할 문제를 열고, 더 없으면 복습 화면으로 이동합니다.
- 보스전은 기존 보스 규칙을 지키기 위해 자동 건너뛰지 않고 '보스 다시 도전'을 안내합니다.
- 틀린 수는 화면에 계속 쌓이지 않습니다. 수동 초기화로도 이전 오답 횟수가 사라지지 않습니다.
- Go Game Guru SGF에 없는 수를 전문적으로 틀렸다고 검증한 것은 아닙니다. 앱의 **원본 정답 수순 일치 여부**를 학습 평가 기준으로 사용합니다.

## 업데이트 방법

1. 업데이트 전 '전체 학습 데이터 백업(JSON)'으로 학습 기록을 보관합니다.
2. GitHub 저장소 최상단에 이 폴더 파일 전체를 업로드하고 같은 이름의 기존 파일을 교체합니다.
3. `sw.js`의 캐시 버전을 변경했습니다. 배포 뒤 옛 화면이면 브라우저의 서비스 워커 등록과 Cache Storage만 갱신합니다. 사이트 데이터 전체 삭제는 기록 유실 위험이 있습니다.
