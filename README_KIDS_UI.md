# Go Life Lab — 초등학생용 사활 UI 개선판 (13단계)

## 아이가 사용하는 법

1. 앱에서 **사활** 메뉴를 선택합니다.
2. **▶ 오늘의 추천 문제 풀기**를 누릅니다. 처음에는 기초 5문제 점검을 시작할 수 있습니다.
3. 바둑판에서 돌을 놓고, 막히면 **💡 힌트 보기**를 누릅니다.
4. **🔍 정답과 해설**을 확인하고 **➡️ 다음 문제**를 풉니다.
5. 원하는 경우 **처음부터 · 쉬운 문제 · 중간 문제 · 어려운 문제**를 선택해 직접 시작합니다.
6. **↺ 틀린 문제 다시 풀기**에서 복습할 수 있습니다.

## 보호자/고급 메뉴

기존 기능은 삭제하지 않았습니다. 사활 아래쪽의 다음 메뉴에서 사용할 수 있습니다.

- **📚 다른 문제 직접 고르기**: 456개 풀이형 문제 목록 및 번호 선택
- **⚙️ 보호자 · 자세한 설정과 전체 문제집**: 원본 422문제 검색, L1~L9 트랙·추천 설정, SGF 가져오기/내보내기/변환
- 각 문제의 **내 도전 기록**, **수순**, **원본 출처 및 저작권**도 필요할 때 펼쳐서 볼 수 있습니다.

## 콘텐츠 및 법적 안내

- 풀이형 456개(기본·변형 35 + Go Game Guru 풀이형 421), 감상용 1개
- Go Game Guru의 쉬움·중간·어려움 420개에는 수순 기반 한글 학습 해설 포함
- 원본 문제의 임시 학습 L1~L9 트랙은 공인 기력이나 전문가의 독립 사활 검증을 뜻하지 않습니다.
- 원본 콘텐츠와 번역·변형 자료에 CC BY-NC-SA 4.0 출처·라이선스 조건을 유지합니다. 비상업적인 학습 목적으로만 배포하세요.
- 학습 기록은 브라우저/기기에 저장됩니다. 중요한 기록은 JSON으로 백업해 주세요.
