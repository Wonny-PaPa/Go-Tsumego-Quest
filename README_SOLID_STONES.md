# Go Life Lab — 바둑돌 표시 오류 수정 (15단계)

## 수정 이유
갤럭시 태블릿과 일부 브라우저에서 사활 문제 또는 자유 연습의 흑돌/백돌이 반투명한 테두리처럼 표시되는 문제가 있었습니다. SVG `radialGradient`와 중복 ID/브라우저 렌더링 차이가 원인일 수 있어, 모든 바둑판의 돌을 명시적인 **불투명 단색**으로 그리도록 수정했습니다.

- 흑돌: `#101816`, 테두리 `#040b08`
- 백돌: `#fffdf5`, 테두리 `#626961`
- 착수 안내용 원형/최근 착수점은 별도 표시
- 사활 문제 / 자유 연습 / 복기 / 기초 연습 모두 동일 처리
- 문제 콘텐츠, 3회 기회 규칙, 기력 추천, 저장·복습 데이터 코드는 변경하지 않음
- 서비스 워커 캐시 이름을 새 버전으로 변경 (`sw.js`)

## GitHub 올리기
ZIP 압축을 풀고 **모든 파일**을 기존 `Go-Tsumego-Quest` 저장소 루트에 업로드합니다. 기존 `index.html`, `sw.js`는 반드시 새 파일로 교체하세요. GitHub Pages 배포 후 기존 앱 창을 닫고 다시 열어 확인하세요. 그래도 예전 바둑돌이 보이면 시크릿 창으로 접속해 버전을 비교하거나 서비스 워커/캐시만 갱신하세요. 학습 기록은 JSON으로 백업한 후 변경하는 것을 권장합니다.

참고: `index.html`만 직접 열면 게임을 실행할 수 있지만 모바일 PWA 설치에는 매니페스트 등 다른 파일이 필요합니다.
